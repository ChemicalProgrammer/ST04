# Configuration exports and repeated runs

Line Setup retains the complete case preview for diagnostics. Its export buttons produce `st-line-configuration-v1`: case metadata and the selected simulation's complete equipment, engine configuration and dynamic settings, including scheduled commands. Other simulations, results and replay are excluded. JSON is lossless, without a compact variant. HTML and printable PDF include parameter tables plus the complete JSON, including nested arrays. The file is an analysis handoff, not a new import format. The in-app Gemini context already includes bounded equipment inputs and engineering checks.

Playback now supports 0.5, 1, 2, 5, 10, 20, 50, 100, 200, 500 and 1000 times real time. At high rates the viewer skips intermediate display samples based on elapsed time; the computed result and all stored samples remain intact. Rendering and browser timer limits can reduce effective speed. This does not accelerate the mathematical solver.

Independent replications and consecutive shifts are now available. See [Shifts, replications and report layouts](25_SHIFTS_REPLICATIONS_AND_REPORT_LAYOUTS.md) for supported ranges, statistical outputs, replay limits and cancellation. Repeating one seed yields the same deterministic result and adds no statistical evidence. Compare baseline and proposal using the same seed list and duration. No startup losses are silently removed and MTBF/MTTR stay fixed except for explicitly documented external interventions. Averages characterize this model, not validation against measured plant performance.
