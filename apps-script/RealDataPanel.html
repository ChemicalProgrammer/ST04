Rate Loss: comparison and calculation

The plant Rate Loss input is comparison-only. It never changes speeds, creates stops or adds a second loss to the simulation. Simulated Rate Loss (min) = line runtime (min) − effective runtime (min). Runtime counts ticks with positive final-output flow; effective runtime sums output / nominal reference speed for each active format. Full stops are downtime. A 2 min ramp at 300 bottles/min producing 300 bottles instead of 600 means 1 min of Rate Loss. Buffers can absorb equipment ramps; equipment losses overlap and must not be summed as line loss. Stop transitions currently model response and residual discharge, not gradual deceleration. Compare the same period, output boundary, runtime definition and reference speeds. Results show each round or their mean; older results require a new run. Recalculated real uses only the times you entered and does not replace reported data.
