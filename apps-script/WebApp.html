    Simulation seeds

    Rounds use base seed + round index. The actual seed is saved with results. This policy is saved in this case and also applies in Basic. What-If comparisons keep matched seeds.

    Simulation engine

    SimPy runs in this browser. Its first run downloads Pyodide over HTTPS. Supports alternating machine–conveyor lines; supports spatial products, packed queues, Prime/Back-up sensors, downtime, ramps and residual discharge. OEE and What-If are not validated for this engine. Changing the engine clears this simulation’s previous results.

    Basic uses manual saving with the Save icon. Choose the seed policy here; duration, rounds and playback speed are set in Simulation.

    Agent response

    The response arrives complete. Progressive reveal is presentation, not live streaming.
