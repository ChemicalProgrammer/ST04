# Crear una aplicación a partir de la plantilla

Usa la plantilla adjunta para crear **[nombre de la aplicación]**.

- Usuarios y finalidad: **[quién la usa y para qué]**.
- Entidades: **[registros, campos, estados y relaciones]**.
- Flujo principal: **[pasos que realiza el usuario]**.
- Datos privados o compartidos: **[alcance por cuenta/equipo]**.
- Operaciones: **[crear, editar, aprobar, exportar, etc.]**.
- Restricciones: **[Apps Script, permisos disponibles, dispositivos, idiomas]**.
- Criterios de aceptación: **[resultados observables]**.

Primero identifica qué componentes se reutilizan y qué contratos cambian. Propón un mapa de archivos y una primera versión funcional pequeña. Conserva las utilidades compartidas de interfaz, transporte, identidad y animación cuando sean aplicables.

Define la validación, persistencia y manejo de errores antes de conectar el formulario. No presentes controles vacíos como funcionalidades terminadas. Si una función queda fuera del alcance, indícalo en la documentación. Actualiza configuración, arquitectura, pruebas e instrucciones de instalación para la nueva entidad.
